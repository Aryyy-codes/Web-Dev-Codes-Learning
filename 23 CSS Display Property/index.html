     display: none;
     This tells the browser to not display the element at all, and it will not take up any space in the layout.
     The element is completely removed from the document flow, and it will not be visible on the page.
       
     visibility: hidden;
     This tells the browser to hide the element, but it will still take up space in the layout.
     The element is still present in the document flow, but it is not visible on the page.
