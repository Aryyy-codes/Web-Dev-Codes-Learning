1. Colors in CSS

CSS mein color set karne ke 5 main tareeke hain. Sab same kaam karte hain — bas likhne ka format alag hai.

Named Color:
color: tomato; background-color: lightyellow;
Hex (#RRGGBB):
background-color: #2d6a4f; — sabse common format
RGB:
background-color: rgb(67, 97, 238); — red, green, blue (0-255)
RGBA (with transparency):
background-color: rgba(255, 99, 71, 0.3); — last value alpha hai (0 = transparent, 1 = solid)
HSL:
background-color: hsl(280, 60%, 45%); — hue, saturation, lightness
HSLA (with transparency):
background-color: hsla(200, 80%, 50%, 0.25); — HSL + alpha
Gradient (Bonus):
background: linear-gradient(135deg, #667eea, #764ba2); — do ya zyada colors blend

1.2em — parent element ke relative

1.2rem — root (html) ke relative, best practice

Spacing

word-spacing: 12px — words ke beech gap

line-height

Tight line-height (1.2).
Second line yahan hai.
Teen lines tight dikhengi.

Normal line-height (1.6).
Second line yahan hai.
Readable spacing.

Loose line-height (2.5).

text-indent

Pehli line indent hoti hai 40px se. Baaki lines normal rehti hain. Books aur articles mein commonly use hota hai paragraph shuru karne ke liye.

text-shadow

Simple shadow — text-shadow: 2px 2px 4px rgba(0,0,0,0.4)

Glow effect — neon jaisa dikhta hai

white-space & text-overflow

Yeh bahut lamba text hai jo box se bahar jaata hai lekin ellipsis (...) se cut ho jaata hai

5. Quick Reference Cheat Sheet

  • color — text ka color
  • background-color — background ka color
  • font-family — font choose karo (fallback stack ke saath)
  • font-size — text ka size (px, em, rem, %)
  • font-weight — boldness (100-900)
  • font-style — normal, italic, oblique
  • text-align — left, center, right, justify
  • text-decoration — underline, overline, line-through, none
  • text-transform — uppercase, lowercase, capitalize
  • letter-spacing — letters ke beech gap
  • word-spacing — words ke beech gap
  • line-height — lines ke beech vertical gap
  • text-indent — pehli line ka indent
  • text-shadow — shadow/glow effect
