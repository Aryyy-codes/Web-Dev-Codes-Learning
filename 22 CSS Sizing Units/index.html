box-sizing: border-box helps as it includes padding and border in the element's total width and height as changing the width normally will change it twice from both the sides.

There also exists a unit called vmin which is the minimum of the viewport's width and height. So if the viewport's width is 1000px and height is 500px then 1vmin will be 5px as the percentage. This is useful when we want to make an element's size relative to the viewport's size. Here vmin is height and vmax is the width whereas it is vice versa in phones.
