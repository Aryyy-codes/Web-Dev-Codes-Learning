Here, I am trying to understand how color specificity and cascade works.

Also the order of specificity matters. The more specific the selector, the higher priority it has in the cascade. As here the inline style has been used which overrides the class selector in this case.

Inline style > ID seslector > Class selector > Element selector

There also exists < !important > which can be used after the color name in style to override the cascade.

We can also calculate the specificity of different selectors as follows:
Universal selector 0
Element selector 1
Class selector 10
ID selector 100
Inline style 1000
For multiple selectors, we can add the specificity values of each selector to get the total specificity.
