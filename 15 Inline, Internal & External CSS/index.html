About CSS additionn in HTML

CSS can be added to HTML in three ways: inline, internal, and external.

1.Inline CSS is applied directly to an HTML element using the style attribute like we did here.

Internal CSS

2.Here the css is added using the style tag in the head section of the HTML document.And the selector and declaration are written inside the style tag.

External CSS

3.Here the css is added using an external .css file that is linked to the HTML document using the link tag in the head section.
